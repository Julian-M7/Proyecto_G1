# RNF-002 — Operación sin conexión a internet

> Ficha de requisito (ISO/IEC/IEEE 29148). Versión de la ficha: Propuesto (supuestos adoptados) · v1.0 (21/11/2026) · Nicolás Bastidas. Plantilla Word equivalente: `fichas-requisito-29148.docx`.

| Campo | Contenido |
|---|---|
| **Identificador · tipo** | RNF-002 · No funcional — fiabilidad y disponibilidad |
| **Enunciado** | **El sistema deberá permitir registrar ventas, anulaciones, movimientos de inventario y egresos, y consultar el stock, el historial y el cierre de caja, sin conexión a internet.** |
| **Plantilla EARS** | Ubicua (aplica siempre). |
| **Justificación** | El local no tiene conexión a internet; si el sistema dependiera de ella no se podría vender ni registrar. Es el obstáculo OB-1 del árbol de metas, resuelto por prevención. |
| **Fuente** | Acta de constitución, sección 3 (restricción) y sección 7 (criterio 6); árbol de metas KAOS, OB-1; entrevista a la empleada (17/09/2026), hallazgo 7. |
| **Propietario** | Camilo Gutiérrez — jefe y propietario. |
| **Trazabilidad hacia atrás** | NI-12 · G1.1 (OB-1) · HU-01 (s) |
| **Prioridad** | Must (supuesto de trabajo; criterio 6 del acta). |
| **Dependencias y conflictos** | RNF-006 (persistencia), RF-001, RF-003, RF-005 y RF-006. Los productos nuevos se crean en el mismo celular, sin conexión (TBD-09); se corrige CU-01, extensión 1a. |
| **Método de verificación** | Prueba · CP-102 |
| **Criterio de aceptación** | En CP-102, con el dispositivo sin conexión a internet (modo avión) durante una jornada de prueba, cada función listada en el enunciado se ejecuta completa y sin mensajes de error de conexión. |
| **Notas y supuestos** | Supuesto: no existe un catálogo externo que sincronizar: el jefe crea y edita los productos en el celular del local (TBD-09). * Depende de un supuesto de trabajo del apéndice C del SRS: el patrocinador valida «correcto» y quien construya valida «factible» en la fase 05. |
